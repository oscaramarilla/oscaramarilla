⚙️ Stack actual
Frontend & framework: Next.js 16 (App Router) · React Server Components · TypeScript · Tailwind CSS · shadcn/ui
Backend & datos: Node.js · Supabase / Neon (Postgres) · Drizzle ORM · Zod · Edge Functions
Infra: Vercel · Squarespace DNS · Cloudflare · GitHub Actions
Operacional: WhatsApp Cloud API (Meta) · pdfBuilderService propio · MDX + Schema.org JSON-LD para SEO B2B · Multi-currency engine reutilizable (PYG/USD/BRL)
Workflow de desarrollo: Cline + VS Code con sistema de skills propio (landing-builder, cotizador-engine, copy-comercial, qa-deploy) — agentes especializados, no IA genérica.

🧭 Cómo trabajo

Diagnóstico operativo gratuito (30 min, WhatsApp). No hay venta. Solo entender si tu cuello de botella se resuelve con software o no.
Propuesta concreta. Alcance, precio fijo, plazo. Sin "depende".
Build en sprints visibles. Vos ves avances reales en cada deploy, no PowerPoints.
Entrega + soporte. El sistema queda funcionando, vos lo usás, yo soy responsable de que no se caiga.

No tomo proyectos donde el cliente quiere "una web bonita pero sin objetivo claro". Sí tomo proyectos donde alguien me dice "perdemos 4 horas por día cotizando manual" o "se nos pasan turnos porque están en cuadernos distintos".

📐 Filosofía

"El código que no factura no existe. La feature que no le ahorra horas al cliente es ruido. Hecho, deployado y usándose es la única definición de terminado."
